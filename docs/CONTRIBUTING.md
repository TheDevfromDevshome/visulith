# Contributing

1. Fork the repository and create a branch from `main`.
2. Run `pnpm install`, `pnpm build`, `pnpm test` before opening a pull request.
3. Keep changes in small, reviewable commits with imperative commit subjects.
4. Add tests for behavior changes, especially validation, generation and migrations.
5. Update `docs/CAPABILITIES.md` when a capability status changes.
6. Never commit generated output (`out/`) or local planning material.

By contributing you agree that your contribution is licensed under Apache-2.0.
